## 🚀 How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/DakshBhalala/PDS.git
   cd PDS
   ```

2. Install dependencies:
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter
   ```

3. Open Jupyter:
   ```bash
   jupyter notebook
   ```
