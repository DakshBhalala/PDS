# Simplilearn: Applied Data Science with Python

Coursework and exercises completed for the **Introduction to Applied Data Science with Python** course by Simplilearn.

---

## 📓 Course Modules

1. **[01_Python_Basics.ipynb](01_Python_Basics.ipynb)**  
   Python basics: variables, data types, lists, dictionaries, loops, functions, and exceptions.

2. **[02_Numpy_Pandas.ipynb](02_Numpy_Pandas.ipynb)**  
   NumPy arrays, matrix operations, and Pandas DataFrames (filtering, grouping, cleaning, sorting).

3. **[03_Data_Visualization.ipynb](03_Data_Visualization.ipynb)**  
   Visualizing data using Matplotlib and Seaborn (bar plots, histograms, heatmaps, pairplots).

4. **[04_Machine_Learning.ipynb](04_Machine_Learning.ipynb)**  
   Machine Learning fundamentals: train-test split, linear regression, and evaluation metrics (MAE, MSE, R²).

---

## 🚀 How to Run

```bash
jupyter notebook
```
Open any of the `.ipynb` files to run the code.
